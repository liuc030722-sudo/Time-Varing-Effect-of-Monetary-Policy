# Time-Varying-Effect-of-Monetary-Policy

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/liuc030722-sudo/Time-Effect-of-Monetary-Policy/main?urlpath=rstudio)

## Project Overview | 项目简介

This project investigates the time-varying relationship between interest rates and inflation across ECB and Federal Reserve leadership regimes using econometric methods.

本项目使用计量经济学方法，研究欧洲央行与美联储不同领导时期利率和通货膨胀之间的动态关系。

## Tools | 使用工具

- R — Data processing, regression analysis and statistical testing
- Stata — Econometric analysis
- Excel — Data preparation

## Methodology | 研究方法

- OLS Regression and HAC Robust Standard Errors
- Instrumental Variables (IV)
- Bai–Perron Structural Break Tests
- Wald Joint Hypothesis Tests
- Central Bank Leadership Regime Comparisons

## Key Findings | 主要发现

The analysis identifies stronger evidence of time variation in the interest rate–inflation relationship for the Federal Reserve than for the ECB. Structural break analysis suggests that major macroeconomic events and leadership periods both matter when interpreting changes in monetary policy relationships.

研究发现，美联储利率与通胀关系的时变性证据强于欧洲央行。结构突变分析表明，在解释货币政策关系的变化时，需要同时考虑宏观经济事件与央行领导时期。
